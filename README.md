# 日本 地震ダッシュボード 🗾

日本で発生した地震が **いつ・どこで・どれくらいの規模・どれくらいの揺れ** だったのかを、
地図・一覧表・統計・時系列グラフでまとめて見られるダッシュボードです。
単一の HTML ファイルだけで動作します（サーバー不要）。

**🔗 公開ページ:** https://tym3104.github.io/japan-earthquake-dashboard/

---

## 主な機能

- **地図表示** — 震源を円で表示。円の色と大きさでマグニチュードを表現
- **一覧表** — 発生日時 / 震源地 / マグニチュード / 深さ / 最大震度
- **絞り込み** — 期間・最小マグニチュード・最小震度・都道府県・「日本近隣のみ」
- **統計サマリー** — 表示件数、最大規模、平均M、最新地震
- **震度分布** — 震度ごとの件数（深刻な震度ほど大きく表示）
- **マグニチュード分布** — 規模帯ごとの件数バー
- **時系列チャート** — 日別／月別で「規模と頻度」を積み上げ表示
- **共有の蓄積履歴** — 週次の自動ジョブが `data/earthquakes.json` を更新。初回訪問者でも過去の蓄積履歴が見える
- **データの自動蓄積** — 取得したデータはブラウザ内にも保存され、共有データ・最新データと自動で結合
- **エクスポート / インポート** — 蓄積データを JSON でバックアップ・復元

---

## 使い方

1. 公開ページを開きます。
2. 初回は自動でデータを取得します（手動で取得したい場合は右上の「データを取得」）。
3. 上部の絞り込みで、見たい期間・規模・震度・地域を選びます。
4. 地図の円や表の行をクリックすると、その地震の観測点ごとの震度詳細が見られます。

> 💡 **データ更新の仕組み**: データは2系統で最新化されます。
> 1. **週次ジョブ（共有）**: GitHub Actions が毎週 `data/earthquakes.json` を更新（誰のブラウザにも依存しない正本）。
> 2. **ページを開いた時（各自）**: 前回取得から1週間以上なら、各自のブラウザがライブAPIから最新分を追加取得。
>
> 起動時はまず共有データを描画し、その後ライブ取得を上乗せします。共有データのおかげで初回訪問者でも履歴が見えます。

## データについて

- **データ提供:** [P2PQuake API](https://www.p2pquake.net/develop/json_api_v2/)（地震情報共有サイト）
- **一次情報:** 気象庁
- **地図:** © [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors

地震データは2か所に保存されます。

- **共有の正本**: リポジトリ内 `data/earthquakes.json`（週次ジョブが更新）。全閲覧者が同じ蓄積履歴を見られます。
- **各自のブラウザ（localStorage）**: 各自がライブ取得した最新分。共有データと自動で統合されます。

> ⚠️ ブラウザ側の蓄積はデータ消去や別端末では引き継がれません（共有データは引き継がれます）。
> 手元に残したい場合は「エクスポート」で JSON バックアップを取得してください。

### 週次データ取得（メンテナ向け）

`scripts/fetch-data.mjs` が P2PQuake API から取得し、重複排除・イベント統合のうえ
`data/earthquakes.json` にマージ保存します（ダッシュボードと同一のマージロジック）。

取得は**期間ベース**です。既定では直近10日分をカバーするまでページを遡り、既存データに
追いついたら打ち切ります（cron間隔の7日より広く取ることで、活発な週に古いレコードが
取りこぼされるのを防ぎます）。

```bash
node scripts/fetch-data.mjs              # 直近10日分をカバー（既定）
SPAN_DAYS=30 node scripts/fetch-data.mjs # カバー期間を変更（初回バックフィルなど）
FETCH_LIMIT=500 node scripts/fetch-data.mjs  # 件数固定の旧挙動（手動バックフィル用）
```

主な環境変数: `SPAN_DAYS`（カバー期間・既定10）、`MAX_PAGES`（安全上限・既定40＝最大4000件）、
`MAX_STORED`（蓄積上限・既定5000）。

自動実行は GitHub Actions（`.github/workflows/weekly-earthquake-fetch.yml`）が担当します。
毎週月曜 09:00 JST に実行され、変更があれば自動コミット・プッシュします。Actions タブから
手動実行（Run workflow）も可能です。

> ℹ️ Claude Code on the web / Cowork のクラウド環境は、ネットワークポリシーで `api.p2pquake.net`
> への外向き通信がブロックされる場合があります。GitHub Actions のランナーは制限がないため、
> 週次取得はこちらで実行する構成にしています。同じ `scripts/fetch-data.mjs` は、ドメインを許可した
> Cowork 環境からも `node scripts/fetch-data.mjs` でそのまま実行できます。
